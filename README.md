## 📱 Responsive Design

This portfolio is fully responsive and tested on:

- **Desktop** (1200px+)

- **Mobile** (320px – 768px)

Breakpoints are handled with CSS media queries for optimal viewing on all screen sizes.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/zjoon/zainab-portfolio.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd zainab-portfolio
   ```

3. **Open `index.html` in your browser:**
   - Double-click the file, OR
   - Use a live server (VS Code extension recommended)
